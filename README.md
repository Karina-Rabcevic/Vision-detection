# Vision Detection

Учебный проект по компьютерному зрению с использованием OpenCV и MediaPipe.

## О проекте

Проект включает две задачи: определение сигналов светофора по цвету и форме световых областей, а также обнаружение и подсчёт людей на видео с помощью модели компьютерного зрения.

## Что реализовано

- Определение красного, жёлтого и зелёного сигналов светофора
- Обработка видео с веб-камеры и из файла
- Поиск цветовых областей и контуров с помощью OpenCV
- Определение формы объектов по контурам
- Обнаружение людей на видео с помощью EfficientDet Lite
- Подсчёт обнаруженных людей в каждом кадре

## Технологии

Python, OpenCV, NumPy, MediaPipe, EfficientDet Lite.

## Статус

Учебный проект.
